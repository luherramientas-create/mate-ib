# Lu Herramientas — Matemáticas AI NM

Repositorio base para herramientas interactivas de Matemáticas del Bachillerato Internacional, Aplicaciones e Interpretación Nivel Medio.

## Primera herramienta

**Funciones exponenciales — AI NM**

La arquitectura está pensada para reutilizar el mismo motor con futuros temas: funciones, probabilidad, estadística y otros contenidos de AI NM.

## Primera fase

MVP de la experiencia del estudiante:

- Selección de sección
- Selección de estudiante
- Menú de preguntas
- Pregunta 1 como prototipo
- Respuestas e intentos
- Pistas progresivas
- Registro de progreso
- Preparación para integración con Firebase/Firestore
- Renderizado matemático con MathJax
